Transparent by design

A benchmark,
not a vibe.

The questions stay fixed. The models change. Reality gets the last word.

01

Fixed questions

Every model receives the same 50 precisely resolvable questions and the same 11 long-horizon end states.

02

Closed book

Models answer from internal knowledge and reasoning only. No browsing, tools, ranges, refusals, or qualitative hedging.

03

Point forecasts

Each answer is a single probability or numeric estimate, paired with a rationale of no more than two sentences.

04

Versioned forever

Each run records model version, knowledge cutoff, and date. New releases add to the timeline instead of replacing history.

05

Scored by reality

Probability questions resolve after December 31, 2030 and can be scored with proper calibration metrics such as the Brier score.

06

Raw data available

The public dataset will include every model response, rationale, prompt version, and aggregate—without smoothing away disagreement.
